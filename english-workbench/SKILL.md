# 英语错题工作台

家长带孩子用，小学英语。工作在当前 AI 对话里完成：Markdown 是长期档案，`工作台.html` 是生成的查看页，PDF/Word 是打印的练习。没有服务器、数据库、定时任务或额外模型密钥；所有材料留在家长自己电脑上。

和数学（mistake-workbench）、语文（chinese-workbench）是**姐妹 Skill**：档案机制相同（同一套脚本、工作台网页），分析逻辑换成英语的，带「三层映射」和「盲区」。三个 Skill 各管一科，数据分科、不混用、不做横向排名。

## 四条铁律

1. **口述优先，读图只找线索。** 具体错词、扣分、选项，一律以家长口述为唯一准源。读图发现和家长说法不一致时，向家长确认，绝不拿读图结论推翻口述。
2. **不写分数、等级、排名。** 只写掌握程度：扎实 / 基本掌握 / 需加强 / 未考察。处数、扣分细节只写进卷子/错题笔记作证据；`check` 拦的是维度/卷子/易错点/盲区笔记正文里的分数。
3. **观察和推测分开，强项单独认。** 口语听力若是孩子的强项，做对就记「已具备」，不再练同类；错题若出现在听说先按口述核实。不把"粗心""不用功"当错因。
4. **出了题不算练了，家长说懂了不算掌握了。** 只有孩子真实作答、帮助情况明确，才记「本次独立完成」；易错点状态只凭作答证据改。

## 第一次用 / 找到档案

档案目录由家长指定。当前目录有 `.错题工作台.json` 就直接用；没有就在家长选中的空目录初始化。不扫描无关目录，不把两个孩子合并。

档案目录由首次 `init` 命令创建（询问家长：孩子称呼、年级、教材版本）。新会话先读 `开始.md`，再读 `档案/课标映射.md`、本次相关卷子、易错点、盲区和最近日志。不凭聊天记忆判断进展。档案格式见 [references/档案格式.md](references/档案格式.md)。

年级或教材变了用 `profile` 更新，不重建档案。第一次用时一次问清三件事，不多问：年级学期、英语教材版本（外研社三年级起点/人教版PEP/其他）、孩子称呼。

课标全国统一用《义务教育英语课程标准（2022 年版）》；3～4 年级对应一级。建议把课标原文 docx 存放在错题本根目录备用（可选）。

## 核心流程：九步

收到卷子后按顺序做，每步写法见 [references/分析模板.md](references/分析模板.md)。

1. **收题**：实际读图，逐题提取题目、答案、红笔批改。原图用 `media` 存档。看不清标「不确定」，关键信息不清才让家长局部确认。
2. **判错与归因**：按 [references/错因分类.md](references/错因分类.md) 定大类小类（语音/词汇/语法/审题/表达）。**口述优先**。
3. **映射课标**：按 [references/课标维度/英语.md](references/课标维度/英语.md) 定六要素落点 → 挂四素养。更新「维度」笔记的 level 和证据。
4. **三层判定（最关键）**：
   - **需巩固**：做错且有证据 → 建/更新「易错点」笔记（tier=需巩固）
   - **已具备**：做对的强项（口语听力）→ 更新「维度」level 为扎实/基本掌握，不再出同类练习
   - **未覆盖**：课标白纸黑字要求、卷子没考 → 建/更新「盲区」笔记（tier=未覆盖，source 填课标页码原文）
   三层结论同时更新到 `档案/课标映射.md`。
5. **对比历史**：「易错点」里找同名点，有就追加出现记录、更新 last_seen，两次以上 status=活跃。
6. **出题**：针对活跃易错点按 [references/出题规范.md](references/出题规范.md) 出 3～5 题——**题目全部从孩子真实错题和课本原文里长出来，不编新场景**。自己先答一遍核对。孩子版、妈妈版两份，`pdf` 转 PDF。
7. **批改**：作答发回先存图，对照妈妈版判对错，更新练习状态、易错点状态、维度 level。
8. **更新工作台**：写卷子笔记、当天日志，重写「开始.md」当前状态，`check` → `build`，回读确认后再说保存好。
9. **期末复习卷**：家长说"出复习卷"时，活跃易错点多出、减少少出、消失不出。

## 看课标覆盖（家长点名时）

打开 `档案/课标映射.md`，按四大核心素养和六要素列出：有考 / 考了一点 / 完全没考，并给出对应盲区笔记链接。参考格式（示例）：口语听力已具备；**词汇记忆、自然拼读运用、语法（词性/介词）**三块需重点补；文化意识、思维品质、读写类待更多试卷到位后逐条定盲区，不提前编造。


## 工作台的四个新视图（2026-11-24 加）

`工作台.html` 除了总览/三层/卷子/练习/日志，还有：

- **错题卡**：一张错题一张卡，直接贴原卷照片（点开放大看整页），错答红删除线、正答绿色，带知识点/易错点标签。原图存 `附件/`，在错题笔记加 `image: 附件/xxx.jpg` 关联；卡片字段 `q`（题干）/`wrong`（错答）/`right`（正答）可选，`build` 会把图片内嵌进 HTML，任何预览方式都看得清。**图只作证据，内容一律以口述为准，不靠 OCR 读图生成。**
- **看板**：错题总数、知识点数、活跃易错点数、已录卷子数；错因分布柱状图、易错点排行榜、错题时间线、一句话诊断。数字全部从档案统计，不写分数。
- **闯关 ⭐**：从 `档案/闯关题库.md` 读题 json（`skill`/`level`/`q`/`opts`/`a`/`why`），按坑分组、4选1、连对3题通关、答错清零并展开错因提醒。题目必须从真实错题长出来，不编新场景；题库为空时页面会提示先建库。
- 题库和卡片字段都是可选的，没有也能 build；`check` 不要求这些字段。

## 命令

```text
python3 "<skill>/scripts/workbench.py" init    --root "<档案>" --child "孩子称呼" --grade "年级学期" --textbook "外研社三年级起点"
python3 "<skill>/scripts/workbench.py" profile --root "<档案>" --grade "四年级下"
python3 "<skill>/scripts/workbench.py" list    --root "<档案>"
python3 "<skill>/scripts/workbench.py" check   --root "<档案>"
python3 "<skill>/scripts/workbench.py" build   --root "<档案>"
python3 "<skill>/scripts/workbench.py" media   --root "<档案>" --source "<原图>" --name "2026-11-24_四上英语期中_第1页.jpg"
python3 "<skill>/scripts/workbench.py" append  --root "<档案>" --note "错题/xxx.md" --text-file "<追加内容.md>"
python3 "<skill>/scripts/workbench.py" pdf     --html "<练习.html>" --pdf "<练习.pdf>"
```

`check` 有错先修再 `build`；`build` 生成 `工作台.html`，打开给家长看。`pdf` 需电脑装有 Chrome 或 Edge。回复先给结论和文件链接，不把脚本、JSON、内部文件交给家长。

## 与台账的关系

`D:\小学\错题本\错题分析台账.xlsx` 是跨科逐题流水账（三科共用），本 Skill 是英语的**能力画像**——把流水账提炼成"能力点+三层状态+课标依据"。两者不冲突：台账记每题错了什么，Skill 记孩子的能力长什么样、该补什么。导入时把逐题记录归并成能力点，不要一条条照搬。
