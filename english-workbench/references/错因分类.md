# 错因分类（英语版）

大类五个：**语音、词汇、语法、审题、表达**。给英语错题贴标签写「大类·小类」，例如「语法·词性」。一道题最多两个标签。每行：小类｜定义｜对应素养维度。本库归纳，配合《课标维度/英语.md》用。

**语音**（对应语言能力）
- 拼读不会用｜学过自然拼读但不会借拼读规则读新词｜语言能力、学习能力
- 字母发音混｜字母在单词中的发音感知错、重音升降调错｜语言能力

**词汇**（对应语言能力、学习能力）
- 词义不通｜借图片实物语境仍理解错词义｜语言能力
- 记不住｜单词反复记不住、不愿记，缺乏音形义策略｜学习能力
- 词形写错｜单词拼写、字母书写错｜语言能力

**语法**（对应语言能力）
- 词性判断｜判断某词是什么词性（如 again 是副词）错｜语言能力
- 介词误用｜介词词义/用法混淆、找同类词错｜语言能力
- 时态形式｜一般现在时/现在进行时形式意义用错｜语言能力

**审题**（对应思维品质、语言能力）
- 没按要求选｜题目要求选正确的/同类的/不同类的，没看清｜思维品质
- 判断依据错｜判断题只凭感觉、说不出依据｜思维品质

**表达**（对应语言能力、文化意识）
- 书写不规范｜字母单词句子书写不正确（课标 1-9）｜语言能力
- 仿写不到位｜参照范例仿写句子时结构/用词错（课标 1-10）｜语言能力
- 交际不得体｜问候、致谢、回应用语不合语境｜文化意识

## 归因纪律（写进每份错题笔记）

1. **口述优先**：具体错词、扣分、选项，一律以家长口述为准。读图只用来发现线索，绝不拿读图结论推翻口述。
2. **观察与推测分开**：看得见的写"她选了介词项"；看不见的写"可能没记住词性分类"。不写"粗心""不用功"当错因。
3. **不写分数、等级、排名**。只写掌握程度：扎实 / 基本掌握 / 需加强 / 未考察。
4. **区分强项**：口语听力是米娅强项，错题若出现在听说，先怀疑是不是记录偏差，按口述核实。
