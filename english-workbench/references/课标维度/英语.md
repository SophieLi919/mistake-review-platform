# 英语课标维度库（义务教育英语课程标准 2022 年版 · 一级 3～4 年级）

## 0. 用法说明

给英语错题贴标签时，先定「语言知识六要素」落点（主题/语篇/语音/词汇/语法/语用），再挂四大核心素养。程度词只用四个：扎实 / 基本掌握 / 需加强 / 未考察，不写分数、不排名。一级对应 3～4 年级，外研社三年级起点教材适用本级别要求。

三层映射（本 Skill 的核心）：
- **需巩固**：卷子考过、做错、有证据 → 建/更新「易错点」（tier=需巩固，status=活跃）
- **已具备**：卷子考过、做对 → 更新对应「维度」level 为扎实/基本掌握，不再出同类练习
- **未覆盖**：课标白纸黑字要求、卷子没考 → 建/更新「盲区」（tier=未覆盖，source 填课标页码原文）

判断"未覆盖"必须回第 2、3 节找课标原文依据，不能凭感觉列。

本库依据《义务教育英语课程标准（2022年版）》一级原文摘录整理，〔第X页〕为课标印刷页码。原文优先，归纳部分标「本库归纳」。

## 1. 四大核心素养（课标第 4～5 页原文）

| 素养 | 课标一句话 | 错题表现（本库归纳） |
|---|---|---|
| **语言能力** | 运用语言和非语言知识及各种策略，参与特定情境下相关主题语言活动时表现出的语言理解和表达能力；是核心素养的基础要素（第4页） | 词形拼写、词性判断、介词、句型仿写、语音拼读、听读理解 |
| **文化意识** | 对中外文化的理解和优秀文化的鉴赏，跨文化认知、态度和行为选择（第5页） | 中外文化标志物、节日饮食、问候称谓得体性 |
| **思维品质** | 人的思维个性特征，反映理解、分析、比较、推断、批判、评价、创造等方面的层次和水平（第5页） | 图片/关键词归纳信息、预测、表达喜恶、一问多解 |
| **学习能力** | 积极运用和主动调整英语学习策略、拓展学习渠道、提升学习效率的意识和能力（第5页） | 记词策略、自然拼读运用、复习调整、合作探究 |

## 2. 学段目标（一级 3～4 年级 · 课标第 6～11 页原文摘要）

**语言能力〔第6～7页〕**
- 感知与积累：感知单词短语句子重音升降调；有意识模仿发音；大声跟读；积累个人喜好/基本信息简单句式；听懂日常指令；借助图片读懂简单小故事；**正确书写字母、单词和句子**
- 习得与建构：识别图片实物/单词短语；根据简单指令反应；体会英语与汉语发音不同；借语音语调手势表情判断情绪态度；语境中理解简单句表意功能
- 表达与交流：围绕主题简单交流，介绍自己和身边人或事物；**书面表达中根据图片或语境仿写简单句子**

**文化意识〔第8～9页〕**：观察辨识中外文化标志物/饮食/节日；用简单词句描述文化图片；大方接触、主动问候、感知人际交往英语表达。

**思维品质〔第9～10页〕**：观察图片现象获取信息；注意不同人看法有差异；据图片关键词归纳语篇重要信息；据标题图片经验预测；表达喜恶，知晓一问多解。

**学习能力〔第10～11页〕**：对英语有兴趣、乐于模仿、敢于表达不怕出错；**能意识到进步与不足并作出调整**；制订简单学习计划；尝试多渠道学习；合作完成学习任务。

## 3. 内容要求六要素（一级 · 课标第 14～34 页原文摘要）

| 要素 | 一级内容要求 | 使用提示 |
|---|---|---|
| **主题**〔第14～15页〕 | 人与自我（身边事物、时间管理、个人喜好、家庭、学校生活、饮食健康）；人与社会（规则、集体、交往、节日）；人与自然（天气季节、自然现象、动物） | 练词造句都挂在主题群里，不孤立背单词 |
| **语篇**〔第18页〕 | 歌谣歌曲韵文；简短对话独白；配图故事叙事日记；人物/物品/地点介绍；书信通知贺卡；提示牌菜单购物单图表 | 阅读题取材用课本真实语篇 |
| **语音**〔第19页〕 | 识别读出26个字母；感知字母在单词中发音；**感知简单拼读规则，尝试借助拼读规则拼读单词**；模仿重音升降调 | **自然拼读学过但没用起来 → 需巩固重点** |
| **词汇**〔第20～21页〕 | 知道单词由字母构成；借图片实物理解词义；据视听提示说单词短语；**据音形义学习词汇，体会语境中的意思** | **不愿记单词 → 需巩固重点**；词性判断错 |
| **语法**〔第21页〕 | 语境中感知简单句表意功能；理解一般现在时和现在进行时形式意义用法；语境中运用语法描述人和物 | **again 词性、介词不懂 → 需补语法（词性/介词）** |
| **语用**〔第23页〕 | 简单称谓语问候语告别语得体交流；基本礼貌用语；对赞扬道歉致谢恰当回应 | 口语听力强项，已具备 |

**语言技能〔第25～26页〕**：理解性——听懂指令、据图标题推测主题、听读看提取信息、课外视听每周≥30分钟、课外阅读1500～2000词；表达性——跟读朗读、**正确书写字母单词句子**、介绍个人家庭学校、描述图片事物、角色扮演、仿写简单句。

**学习策略〔第31～34页〕**：元认知（集中注意、倾听思考、主动请教、意识进步不足并调整）；认知（词语与事物建立联系、新旧知识联系、**语境中学词汇语法、通过分类加深词汇理解记忆**）；交际（没听懂请对方慢说/重复）；情感管理（有兴趣、敢开口、愿合作）。

**教学提示〔第35～36页〕**：突出听说重视模仿；**词汇采用音形义用结合、语境中反复再现，避免脱离语境的机械记忆与操练**；语法遵循形式意义使用统一原则；围绕语篇主题设计逻辑关联活动。

## 4. 学业质量检查清单（一级 · 第 42～43 页表 22）

阅读/答题做错时逐条对照定位缺什么：
- 1-3 借图片手势听懂简单指令并反应；1-6 跟读时模仿语音语调
- 1-9 **正确书写所学单词和句子**；1-10 参照范例仿写简单句
- 1-5 读配图故事能积极思考、尝试提问；1-11 观察生活语言文化现象、从不同角度看事物

## 5. 能力画像示例（真实使用归纳）

**已具备（不用练）**
- 口语、听力（听说强项，一级教学提示的核心目标已达成）
- 语言能力与语用：简单交流、问候回应得体

**需巩固（有证据）**
1. 词汇记忆——不愿记单词；课标第20～21页"据音形义学习词汇"+ 第36页"避免脱离语境机械记忆"是练法依据
2. 自然拼读运用——学过但不记得、没用起来；课标第19页"借助拼读规则拼读单词"
3. 语法基础——`again` 判断词性、找同类词（介词）错，这块不懂；课标第21页语法知识
4. 词形书写——要求能正确书写单词句子（第19/26页），待卷子证据核实

**未覆盖（盲区，卷子没考——待更多试卷/作业到位后逐条定，不提前编造）**
- 文化意识类：中外文化标志物、节日饮食对比（课标第8～9、24页）
- 思维品质类：据图归纳、预测、表达喜恶、一问多解（课标第9～10页）
- 读写类：仿写句子、配图故事阅读理解、规范书写（课标第26、43页）
- 课外视听每周≥30分钟、课外阅读1500～2000词（课标第26页，过程性，卷面考不出）

**已知考试**：考试记录以卷子笔记为准（按铁律，分数不写进维度正文，只在卷子笔记作证据）。
