# 出题规范（语文版）

核心原则：**不做新题，从孩子自己错过的题里长出来**。常见特点是"会想但写不准、写不全"，练的是把心里知道变成卷面准确；表达若已是强项就不练想象力，练落笔准确。按孩子实际情况调整。

## 五类巩固题（对应课标三层里的"需巩固"）

1. **看清要求**（审题类）：圈出题干里的要求词（"用原文""结合内容谈""至少两条""不正确"），给她几句答法判断合不合要求。
2. **把字写准**（字形字音类）：形近字对比组词、错字改正、前后鼻音选择。字全部取自她的错字：择/坚竖/柱/恢/辞词/橙橘、萤·赢 yíng。
3. **阅读找全**（提取概括类）：**直接用她做过的原文重新设问**（如《扁豆生长的奥秘》《蜻蜓的飞行》），练概括两方面、按原文填空、找时间词、信息提取别把标点抄进去。
4. **结合谈**（表达类）：给"观点+例子+小结"三步骨架，填空逼她把漏掉的"例子"那一步补上（精卫印象、方帽子店观点）。
5. **默写**（积累类）：易错字单独过关——"橙黄橘绿"、"故=成为/变为"、名言"人非生而知之者"。

## 硬规矩

- 题目只从真实错题和课本原文里取材，不编新场景、不编作家作品。
- 每类 3～5 题，一套练习总量控制在一页 A4 以内。
- 孩子版**只有题目**，可直接打印；妈妈版**答案+讲解**，另起一页或单独文件。
- 每题答案写清"错在哪、下次怎么改"，不说"粗心"。
- 阅读题用过的原文要标出处卷子，方便对照。

## 从"未覆盖"盲区出题（家长点名要补时才做）

盲区是卷子没考的，不混进上面的错题练习。家长说"补盲区"时，按《课标维度/语文.md》第 3 节单独出：
- 整本书阅读：读完一章后讲主要内容、分享感受的记录单
- 思辨性表达：事实vs观点判断、找证据、列提纲/思维导图
- 观察手记/日记：观察一样东西，用表格记录
- 应用文：写留言条、请假条、短信息
- 跨学科小调查：提出一个问题、搜集资料、写简单研究报告

## 出题后自检

- 每道题自己先答一遍，确认答案唯一、表述准确。
- 检查有没有混进分数、等级。
- 检查题目是不是都能追溯到某条错题或某条课标要求（不能就删掉）。
