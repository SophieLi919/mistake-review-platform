# 错因分类（语文版）

大类六个：**字形、字音、积累、审题、提取、表达**。给语文错题贴标签时写「大类·小类」，例如「字形·形近字」。一道题最多两个标签。每行：小类｜定义｜米娅例子｜对应素养维度。本库归纳，配合《课标维度/语文.md》用。

**字形**（对应文化自信、语言运用）
- 形近字混｜偏旁或部件写错｜"择"写成言字旁、"坚"写成"竖"、"柱"写错｜语言运用
- 多笔少笔｜多写一点、少写一横｜"恢"多一点、"橙"写成"橘"｜语言运用
- 同音替换｜用同音字代替本字｜"修辞"写成"词"｜语言运用

**字音**（对应语言运用）
- 前后鼻音｜in/ing、en/eng 不分｜"萤 yíng""赢 yíng"选成前鼻音｜语言运用
- 多音多义｜语境中读音判断错｜加点字选择读错｜语言运用

**积累**（对应文化自信、语言运用）
- 默写写不准｜会背但落笔错字、漏字｜"橙黄橘绿"空了"绿时"｜语言运用
- 记忆混淆｜两句诗文张冠李戴｜《题西林壁》填错句、名言顺序写反｜文化自信
- 实词释义空｜文言实词不知道意思就空着｜"故"空着没写｜文化自信、语言运用
- 文学常识｜作者、国籍、出处记错｜安徒生国籍（丹麦非英国）｜文化自信

**审题**（对应思维能力、语言运用）
- 没按指定方式答｜要求"用原文回答""结合故事内容""结合生活实际"没照做｜精卫印象没结合故事内容、方帽子店没结合生活实际｜思维能力
- 答不全｜要求两条只写一条，或要素写残｜视力因素第二条只写"姿势"｜思维能力
- 答太少｜开放题字数/要点明显不足｜保护视力办法写太少｜语言运用
- 分类多选｜要求选一项多选，或判断依据错｜批注问题分类选了一二两项｜思维能力

**提取**（对应思维能力）
- 标点当答案｜把句号、标点抄进答案｜红墨水题写成"句号"｜思维能力
- 图表读错｜统计表、示意图结论读偏｜视力调查表结论不完整｜思维能力
- 概括漏要点｜抓不住两方面/主要原因｜蜻蜓阅读漏答"飞行的奥秘"｜思维能力
- 填空要素乱｜按原文填空时要素错乱、语句不通｜扁豆观察按时间顺序写乱｜语言运用、思维能力

**表达**（对应思维能力、审美创造）
- 赏析写不全｜词句赏析只答感觉，没答手法+内容｜"偷偷"只答"可爱"｜审美创造
- 观点没证据｜有观点但不结合文本/生活举例｜精卫印象、方帽子店｜思维能力
- 举例不当｜举例与题目或前题重复｜发明举例又写"飞机"｜思维能力
- 病句找不全｜修改病句找不出全部错误｜语段修改只改部分｜语言运用
- 句式仿写（强项，一般不算错）｜比喻/拟人/设问/排比仿写｜米娅全对，记录为已具备｜语言运用、审美创造

## 归因纪律（写进每份错题笔记）

1. **口述优先**：具体错字、扣分、选项、篇名，一律以家长口述为准。读图只用来发现线索，绝不拿读图结论推翻口述（这是踩过三次的坑）。
2. **观察与推测分开**：看得见的写"她写了'姿势'"；看不见的写"可能是写太快漏字"。不写"粗心""能力差"当错因。
3. **反思条归属**：米娅铅笔写的"因为……所以……"是**孩子自评**（元认知证据），不是老师批语。老师红笔批改单独标注。
4. **不写分数、等级、排名**。只写掌握程度：扎实 / 基本掌握 / 需加强 / 未考察。
