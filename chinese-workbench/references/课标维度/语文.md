# 语文课标维度库（义务教育语文课程标准 2022 年版 · 第二学段 3～4 年级）

## 0. 用法说明

给语文错题贴标签时，走三步：**先定板块**（四板块之一）→ **再定任务群**（六任务群之一）→ **挂素养**（四素养，可多选）。程度词只用四个：扎实 / 基本掌握 / 需加强 / 未考察，不写分数、不排名。

三层映射是语文版特有的第三只眼：
- **需巩固**：卷子考过、做错了、有证据（对应「维度」笔记 level=需加强，「易错点」活跃）
- **已具备**：卷子考过、做对了（level=扎实/基本掌握），不用再练
- **未覆盖**：课标白纸黑字要求、但这几套卷根本没考到（对应「盲区」笔记 status=未覆盖）

本库依据 Sophie 放在 `D:\小学\错题本\` 的《义务教育语文课程标准（2022年版）第二学段原文摘录.docx》整理，〔第X页〕为课标印刷页码。原文优先，归纳部分标「本库归纳」。

## 2. 四板块 · 第二学段学段要求（课标第 9～11 页原文摘要）

### 识字与写字〔第9页〕
- 主动识字；累计认识 2500 字左右，其中 1600 字左右会写；能用音序和部首检字法查字典
- 写字姿势正确，硬笔熟练写正楷，规范端正整洁；毛笔临摹正楷字帖
- 感知汉字形、音、义联系，初步感受汉字文化内涵
- **学业质量**（第38页）：能根据具体语境辨析多音多义字读音字义，**辨识、纠正常见错别字**；硬笔规范端正整洁书写 1600 字

### 阅读与鉴赏〔第9～10页〕
- 普通话正确流利有感情朗读；初步学会默读（不出声、不指读）；学习略读粗知大意
- 联系上下文理解词句，体会关键词句表达情意的作用；体会句号逗号用法，了解冒号引号用法
- **初步把握文章主要内容，体会思想感情**；学习圈点批注；能对不理解的地方提出疑问
- 复述叙事性作品大意，感受生动形象和优美语言；诵读优秀诗文，领悟大意
- **阅读整本书**，初步理解主要内容，主动分享（第10页）
- 积累优美词句、精彩句段；**背诵优秀诗文 50 篇（段）**；**课外阅读总量不少于 40 万字**；养成读书看报习惯

### 表达与交流〔第10～11页〕
- 乐于口头、书面交流分享，增强表达自信心
- 认真倾听、把握主要内容并简要转述；就不理解处请教、不同意见商讨
- 清楚明白讲述见闻，说出感受想法；讲述故事力求具体生动
- 观察周围世界，不拘形式写见闻感受想象，把印象最深的内容写清楚；**能用便条、简短信件交流**；习作中运用积累的语言材料
- 学习修改习作中有明显错误的词句；根据表达需要正确使用冒号引号；**课内习作每学年 16 次左右**

### 梳理与探究〔第11页〕
- 尝试分类整理学过的字词；发现汉字形音义和书写特点帮助识字写字
- 组织语文实践活动，学会合作；观察大自然、观察社会；**可用表格、图像、音频等多种媒介呈现观察与探究所得**
- 提出学习和生活中的问题，有目的地搜集资料，共同讨论，**尝试运用语文并结合其他学科知识解决问题**

## 3. 六大学习任务群 · 第二学段学习内容（课标第 20～35 页原文摘要）

| 任务群 | 第二学段学习内容要点 | 三套卷覆盖情况 |
|---|---|---|
| **语言文字积累与梳理**〔第21页〕 | 独立识字写字、梳理形音义联系；关注汉字标点正确使用、互相正字正音；诵读积累成语典故、名言、古诗词、精彩句段，分类整理 | **有考**：看拼音写词语、注音、错别字、古诗名言默写 |
| **实用性阅读与交流**〔第24页〕 | 阅读家庭学校社会生活短文，口头书面表述见闻；**写留言条、请假条、短信息、简单书信**；阅读说明大自然的短文，**写日记、观察手记**；讲述革命英雄、传统美德故事 | **考了一点**：视力调查表读图、保护视力建议；应用文/观察手记没考 |
| **文学阅读与创意表达**〔第26～27页〕 | 阅读讲述革命/爱国/历史人物故事；阅读诗歌散文，用文学语言表达情感；阅读儿童文学，**创编儿童诗和故事，发展想象力** | **有考**：神话单元阅读、想象作文《马良来到我身边》（没扣分，强项） |
| **思辨性阅读与表达**〔第29页〕 | 阅读科学短文，依据事实细节表达观点；读中华智慧故事，用**列提纲、画思维导图**表达道理；主动记录整理交流发现的问题，**学习辨析、质疑、提问** | **几乎没考**：只有零星提问分类题，且做错；观点表达没结合内容/实际 |
| **整本书阅读**〔第32页〕 | 读英雄模范图书、儿童文学名著（《稻草人》《爱的教育》）、中国寓言神话传说，讲述大意、分享启示 | **完全没考**：40 万字课外阅读、整本书分享零覆盖 |
| **跨学科学习**〔第34～35页〕 | 运用科学艺术信息科技设计朗诵会故事会戏剧节；参观物质文化遗产、关注传统节日节气民俗；**调查日常问题、写简单研究报告** | **完全没考**：观察、调查、报告零覆盖 |

## 4. 学业质量描述里可直接当"检查清单"的句子（第 38～40 页）

阅读题做错时，逐条对照这几句定位缺什么：

- 阅读中主动识字；根据语境辨析多音多义字，**辨识纠正常见错别字**（第38页）
- 阅读常见图文结合材料，注意**图文关联**，初步把握材料主要内容（第38页）
- 喜爱阅读童话寓言神话；阅读中**提取主要信息**，借助经验预测情节；**结合关键词句解释人物行为，从某个角度分析和评价人物**（第38页）
- 能借助上下文语境，说出**关键语句、标点符号、图表在表达中的作用**；能复述故事，**概括文本内容**（第38页）
- 能诵读优秀诗文，尝试用不同语气语调表达理解与感受（第39页）
- 参加跨学科学习，乐于观察提问交流；搜集整理信息资料，**用照片图表视频文字展示学习成果**（第40页）

## 5. 从米娅三套卷归纳的能力点清单（本库归纳，非课标原文）

供建「维度」「易错点」笔记时直接选用 name / dimension 字段：

**需巩固（有错题证据）**
1. 形近字与音近字字形辨识（择/坚竖/柱/恢/辞词/橙橘）
2. 前后鼻音与易读错字音（萤 yíng、赢 yíng）
3. 古诗文与名言默写准确（橙黄橘绿、"故"、名言顺序、《题西林壁》）
4. 文言实词释义（故=成为/变为）
5. 按要求作答（用原文答、结合故事内容谈、结合生活实际谈、至少两条）
6. 信息提取与概括（把句号当答案、统计表结论、两方面概括、飞行之王填空）
7. 词句赏析写全（"偷偷"拟人只答"可爱"）
8. 提问策略与问题分类（问题分类多选、没写答案）
9. 修改病句找不全
10. 答题完整度（答太少、漏字漏要素）
11. 联想举例恰当（发明举例与前题重复）

**已具备（做对了，不用练）**

12. 句式仿写（比喻/拟人/设问/排比）
13. 想象作文与创意表达
14. 基础看拼音写词语
15. 口语交际对话补充

**未覆盖（盲区，卷子没考）**

16. 整本书阅读与分享
17. 思辨性表达（事实观点分开、找证据、列提纲思维导图）
18. 观察手记与日记
19. 日常应用文（留言条/请假条/短信息/书信）
20. 跨学科调查与简单研究报告
21. 朗读/默读/复述（过程性，卷面考不出，需家里观察）
22. 字词分类梳理（归类识字）
