# 语文错题工作台

家长带孩子用，小学语文。工作在当前 AI 对话里完成：Markdown 是长期档案，`工作台.html` 是生成的查看页，PDF/Word 是打印的练习。没有服务器、数据库、定时任务或额外模型密钥；所有材料留在家长自己电脑上。

和数学错题工作台（mistake-workbench）是**姐妹 Skill**：档案机制相同（同一套脚本、工作台网页），分析逻辑换成语文的，多了「三层映射」和「盲区」。两个 Skill 各管一科，不混用。

## 四条铁律

1. **整页识别，错处口述。** 拍照先识别整页内容——**做对的和做错的都要识别**：对的部分是「已具备/未覆盖」判断的证据；只有错的部分（错字、错答、订正、当时怎么想的）需要家长口述补充。识别与口述冲突时，以口述为准，绝不拿读图结论推翻口述。（踩过三次坑：糊照片、高清照片都读错过。）并提醒家长：**一次拍一小版**（半页或单面），别拍一整张横版摊开的两面，小版识别更准。
2. **不写分数、等级、排名。** 只写掌握程度：扎实 / 基本掌握 / 需加强 / 未考察。错题的处数、扣分细节若家长口述给出，只写进「卷子/错题」备注作证据，`check` 拦的是维度/卷子/易错点/盲区笔记正文里的分数。
3. **观察和推测分开，反思条归孩子。** 看得见的写"她写了'姿势'"；看不见的写"可能写太快漏字"。孩子铅笔写的"因为……所以……"是**孩子自评**（元认知证据），不是老师批语；老师红笔批改单独写。不把"粗心""能力差"当错因。
4. **出了题不算练了，家长说懂了不算掌握了。** 只有孩子真实作答、帮助情况明确，才记「本次独立完成」；易错点状态只凭作答证据改。

## 第一次用 / 找到档案

档案目录由家长指定。当前目录有 `.错题工作台.json` 就直接用；没有就在家长选中的空目录初始化。不扫描无关目录，不把两个孩子合并。

孩子的档案已建在 `D:\小学\错题本\语文错题\孩子`（称呼孩子 / 四年级上 / 部编版）。新会话先读 `开始.md`，再读 `档案/课标映射.md`、本次相关卷子、易错点、盲区和最近日志。不凭聊天记忆判断进展。档案格式见 [references/档案格式.md](references/档案格式.md)。

年级或教材变了用 `profile` 更新，不重建档案。第一次用（还没 profile）时一次问清三件事，不多问：年级学期、语文教材版本（部编版/其他）、孩子称呼。

## 核心流程：九步

收到卷子后按顺序做，每步写法见 [references/分析模板.md](references/分析模板.md)。

1. **收题**：实际读图，逐题提取题目、答案、红笔批改、反思条。原图用 `media` 存档。看不清标「不确定」，关键信息不清才让家长局部确认。
2. **判错与归因**：按 [references/错因分类.md](references/错因分类.md) 定大类小类（字形/字音/积累/审题/提取/表达）。**口述优先**。反思条归孩子自评。
3. **映射课标**：按 [references/课标维度/语文.md](references/课标维度/语文.md) 定板块 → 定任务群 → 挂四素养。更新「维度」笔记的 level 和证据。
4. **三层判定（语文特有，最关键）**：
   - **需巩固**：做错且有证据 → 建/更新「易错点」笔记（tier=需巩固）
   - **已具备**：做对的强项 → 更新「维度」level 为扎实/基本掌握，不再出同类练习
   - **未覆盖**：课标白纸黑字要求、这几套卷没考 → 建/更新「盲区」笔记（tier=未覆盖）
   三层结论同时更新到 `档案/课标映射.md`。
5. **对比历史**：「易错点」里找同名点，有就追加出现记录、更新 last_seen，两次以上 status=活跃。
6. **出题**：针对活跃易错点按 [references/出题规范.md](references/出题规范.md) 出 3～5 题——**题目全部从孩子真实错题和课本原文里长出来，不编新场景**。自己先答一遍核对。孩子版、妈妈版两份，`pdf` 转 PDF。家长点名"补盲区"时，另按盲区出题。
7. **批改**：作答发回先存图，对照妈妈版判对错，更新练习状态、易错点状态（活跃/减少/消失）、维度 level。
8. **更新工作台**：写卷子笔记、当天日志，重写「开始.md」当前状态，`check` → `build`，回读确认后再说保存好。
9. **期末复习卷**：家长说"出复习卷"时，活跃易错点多出、减少少出、消失不出。

## 看课标覆盖（家长点名时）

打开 `档案/课标映射.md`，按六大任务群列出：有考 / 考了一点 / 完全没考，并给出对应盲区笔记链接。孩子当前状况（2026-11 三套卷）：语言文字积累与梳理、文学阅读与创意表达有考；实用性阅读与交流考了一点；**思辨性阅读与表达、整本书阅读、跨学科学习三群几乎零覆盖**。


## 工作台的四个新视图（2026-11-24 加）

`工作台.html` 除了总览/三层/卷子/练习/日志，还有：

- **错题卡**：一张错题一张卡，直接贴原卷照片（点开放大看整页），错答红删除线、正答绿色，带知识点/易错点标签。原图存 `附件/`，在错题笔记加 `image: 附件/xxx.jpg` 关联；卡片字段 `q`（题干）/`wrong`（错答）/`right`（正答）可选，`build` 会把图片内嵌进 HTML，任何预览方式都看得清。**错题卡的错答/订正内容以口述为准；整页对错识别只服务于课标覆盖判断，不拿来推翻口述。**
- **看板**：错题总数、知识点数、活跃易错点数、已录卷子数；错因分布柱状图、易错点排行榜、错题时间线、一句话诊断。数字全部从档案统计，不写分数。
- **闯关 ⭐**：从 `档案/闯关题库.md` 读题 json（`skill`/`level`/`q`/`opts`/`a`/`why`），按坑分组、4选1、连对3题通关、答错清零并展开错因提醒。题目必须从真实错题长出来，不编新场景；题库为空时页面会提示先建库。
- 题库和卡片字段都是可选的，没有也能 build；`check` 不要求这些字段。

## 命令

```text
python3 "<skill>/scripts/workbench.py" init    --root "<档案>" --child "孩子" --grade "四年级上" --textbook "部编版"
python3 "<skill>/scripts/workbench.py" profile --root "<档案>" --grade "四年级下"
python3 "<skill>/scripts/workbench.py" list    --root "<档案>"
python3 "<skill>/scripts/workbench.py" check   --root "<档案>"
python3 "<skill>/scripts/workbench.py" build   --root "<档案>"
python3 "<skill>/scripts/workbench.py" media   --root "<档案>" --source "<原图>" --name "2026-11-24_四上语文第三单元_第1页.jpg"
python3 "<skill>/scripts/workbench.py" append  --root "<档案>" --note "错题/xxx.md" --text-file "<追加内容.md>"
python3 "<skill>/scripts/workbench.py" pdf     --html "<练习.html>" --pdf "<练习.pdf>"
```

`check` 有错先修再 `build`；`build` 生成 `工作台.html`，打开给家长看。`pdf` 需电脑装有 Chrome 或 Edge。回复先给结论和文件链接，不把脚本、JSON、内部文件交给家长。

## 与台账的关系

`D:\小学\错题本\错题分析台账.xlsx` 是跨科逐题流水账（三科共用），本 Skill 是语文的**能力画像**——把流水账提炼成"能力点+三层状态+课标依据"。两者不冲突：台账记每题错了什么，Skill 记孩子的能力长什么样、该补什么。导入台账数据到 Skill 时，把逐题记录归并成能力点，不要一条条照搬。
