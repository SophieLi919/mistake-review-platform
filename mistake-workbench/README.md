# 错题工作台 · mistake-workbench

> 不是把错题发给 AI 让它讲一遍，而是先找到「考什么」的标尺，再把整张卷子交给 AI 按能力维度分析、累积、出题、复查。

这是木妈AIdea 在家用的错题方法，做成了一个 AI Skill（Claude Code、Codex、腾讯 WorkBuddy 等支持 Skill 的 Agent 通用）。它做的事：

1. **先问三件事**：孩子几年级、哪个版本的数学课本、怎么称呼。
2. **收整张卷子**：每页一张照片，不只拍错题。AI 逐题读图，判对错、归错因。
3. **对照课标和教材**：按教育部《义务教育数学课程标准（2022 年版）》的 11 个核心素养维度，和教材单元目标，给出每个维度的掌握程度。**只写掌握程度，不写分数。**
4. **累积易错点**：每个易错点一份笔记，按日期追加出现记录，状态在「活跃 / 减少 / 消失」之间流动。
5. **推测特点关系**：家长提供孩子的聊天记录或观察时，AI 只做推测、标置信度，不下结论。
6. **出两份 PDF**：孩子版只有题；妈妈版每题写练的易错点、提升的维度、做的时候看什么，附错误类型记录表和答案。
7. **批改、更新工作台**：孩子做完拍照发回，AI 批改、更新状态，生成一个本地网页 `工作台.html`。
8. **期末按易错点出复习卷**。

所有材料留在你自己的电脑上，没有服务器，没有账号。

## 安装

**方法一：有 git**

```bash
git clone https://github.com/vickysy/mistake-workbench ~/.claude/skills/mistake-workbench
```

用 Codex 的把目标路径换成 `~/.codex/skills/mistake-workbench`，用 WorkBuddy 的换成 `~/.workbuddy/skills/mistake-workbench`。装过的更新：进入目录运行 `git pull`。

**方法二：没有 git**

GitHub 页面点绿色的 Code → Download ZIP，解压，然后：

- Mac：双击解压出来的 `install.command`（第一次可能要右键 → 打开）。
- Windows：双击 `install.bat`。

脚本会把整个文件夹复制到你电脑上已有的 Skill 目录（Claude Code、Codex、WorkBuddy 有哪个装哪个），不会动别的东西。

**WorkBuddy 看不到 Skill？** 重启一次 WorkBuddy，或在它的 Skill 设置里手动导入这个文件夹。

## 怎么用

1. 在电脑上建一个空文件夹，比如「木木的错题工作台」，在 AI 里选中它（Claude Code 在这个目录里启动，WorkBuddy 把它设为工作目录）。
2. 说：**「错题工作台，帮我分析这套卷子」**。它会先问孩子几年级、哪个版本的课本、怎么称呼。
3. 拍孩子做过的整张卷子或作业，每页一张，**遮住姓名、班级、学校**，发给它。
4. 它先给一页「初步诊断」：考了哪些维度、各掌握到什么程度、错误分几类、最该先补什么。看完没异议它就往下做：建易错点、出练习、生成工作台页。
5. 它问你有没有孩子的聊天记录、错题本或你观察到的特点。有就发给它，它会写进「孩子画像」，分析时只做推测；没有就以卷面为主。
6. 打印「孩子版 PDF」给孩子做，自己看「妈妈版 PDF」。孩子做完拍照发回，说「批改练习」。
7. 以后每张卷子都这么发。期末说「出复习卷」，它按易错点的活跃程度分配题量。

常用的话：「整理错题」「出练习」「批改练习」「更新工作台」「出复习卷」「看看易错点」「孩子升到四年级下了」。

## 文件夹里有什么

```text
SKILL.md                     给 AI 的说明书：铁律、首次设置、九步流程
scripts/workbench.py         本地档案工具：init / profile / check / build / media / append / pdf
assets/workbench.html        工作台网页模板
assets/练习·孩子版模板.html   练习的孩子版模板
assets/练习·妈妈版模板.html   练习的妈妈版模板
references/课标维度/数学.md   2022 版课标：三会、11 个核心素养、三个学段要求、按年级速查
references/教材目标/          北师大版、人教版、苏教版 1～6 年级单元目标库
references/错因分类.md        错因大类、小类
references/分析模板.md        逐题表、维度程度怎么定、特点关联怎么写
references/出题规范.md        两版练习怎么出
references/档案格式.md        档案目录和每种笔记的格式
install.command / install.bat 一键复制到 Skill 目录
```

## 要注意的

- **课标是全国统一的**（2022 年版），教材版本只影响单元定位。三个版本 2024 年起都在按新课标换新教材，单元名对不上时以课本目录为准，教材目标库文末有新旧对照。
- 教材目标库里的「单元目录」核对自电子课本，「教学目标 / 重点 / 难点」是教案的压缩表述，不是教参原文。有课本和教参以它们为准。
- 其他版本（沪教版、西师版、青岛版等）：拍课本目录页给 AI，它会整理成 `档案/教材目录.md` 再定位。
- 生成 PDF 需要电脑有 Chrome 或 Edge；没有就在浏览器里打开 HTML 按 Ctrl/Cmd+P 打印。
- AI 读图可能看错数字。初步诊断里标「不确定」的题，请对照原卷看一眼。
