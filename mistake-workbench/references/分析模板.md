# 分析模板

## 逐题表（写进卷子笔记）
| 题 | 考点（单元目标） | 结果 | 看得见的 | 可能的原因（错因小类） | 维度 |
结果只有三种：对 / 错 / 不确定。「看得见的」抄卷面：他写了什么、老师怎么批。「可能的原因」用错因分类的小类名，最多两个。

## 错题笔记的分析段
1. 先一两句具体结论：这题错在哪一步，属于哪个错因小类。
2. 依据：卷面上的哪个数字、哪一行。
3. 不能确定的部分单独写，不压缩成确定。
4. 正确思路联系本题条件讲，不贴通用模板。

## 维度程度怎么定
- 扎实：这个维度相关的题全对，或只有一处失误且不是维度本身的问题。
- 基本掌握：有对有错，错的能从卷面看出是哪一步。
- 需加强：同一维度多处错，或错在维度的核心要求上（例如运算能力的「正确运算」）。
- 未考察：这张卷子没有相关题。
程度只描述这张卷子和之前记录的综合，不预测期末。每次更新写一行「程度变化」。

## 和特点的关联（写进易错点笔记）
格式固定：「可能和〔特点〕有关，依据〔画像里的证据〕，置信度〔低 / 中〕。」
- 一个易错点最多写两条关联。
- 画像里没有证据就写「暂无线索」。
- 不写「因为他粗心」「因为他聪明」这类没法检验的话。

## 卷子的「掌握程度」一行
按维度写，不按题写。例：「概念理解扎实；估算与应用基本掌握；计算准确需加强；检验习惯还没建立。」

## 历史对比怎么写
在易错点笔记「出现记录」里按日期追加。卷子笔记里加一节「和之前比」：哪些易错点再次出现、哪些上次有这次没有、哪些是新的。只陈述，不评价。

## 三层判定（每张卷子必做，写进卷子笔记 + 档案/课标映射.md）
- **需巩固**：本卷 X 题错在……，已记入易错点 PF-xxx（tier=需巩固），要出专项练。
- **已具备**：本卷 Y 题做对（如解决问题全对＝模型意识/应用意识），把对应维度 level 标扎实/基本掌握，不再出同类练习。
- **未覆盖**：课标第 X 页要求 Z，本卷及前几套都没考 → 建盲区笔记（tier=未覆盖、source 填课标页码原文），家长点名才补。
诊断回复里三层各一句，不写分数。家长有异议按口述改。

## 初步诊断的回复格式（第一次收卷）
```
这张卷子考了：{单元目标} → 对应课标 {核心素养/三会} 维度
掌握程度：{维度}—{扎实/基本掌握/需加强}（证据：{一句卷面表现}）
错了 {N} 处，分类：{计算X / 读题Y / 概念Z …}
三层结论：
  需巩固：{最该先补的一两点}
  已具备：{做对的强项，不用再练}
  未覆盖：{课标要求但没考到的，标进盲区}
最值得先补：{一句话}
```
