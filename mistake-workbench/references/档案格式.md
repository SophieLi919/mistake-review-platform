# 档案格式

```text
错题工作台/
  .错题工作台.json     目录标识，含孩子信息 profile（称呼、年级学期、教材版本）
  开始.md              孩子信息、当前状态与接续约定
  档案/孩子画像.md     特点、证据、更新日期（只做推测依据；没有材料就写「暂无线索」）
  档案/教材目录.md     教材不是北师大/人教/苏教时，按家长拍的课本目录整理
  档案/课标映射.md     三层映射总表：需巩固/已具备/未覆盖 + 课标条目覆盖情况
  维度/                一个维度一份：数学·运算能力.md …
  易错点/              一个易错点一份，正文里按日期追加出现记录（= 需巩固层）
  盲区/                一个课标未覆盖点一份（= 未覆盖层）
  卷子/                一张卷子一份，含逐题表和错题链接
  错题/                一题一份
  练习/                一次练习一份，链接孩子版、妈妈版 PDF
  日志/                一天一份
  附件/                原图、作答照片、PDF、练习 HTML
  工作台.html          生成页，别手改
```

所有链接相对档案根目录，用 `[[目录/文件名|显示名]]`；附件用 `![[附件/文件名.jpg]]` 或 `[[附件/文件名.pdf|孩子版 PDF]]`。属性区一行一个值，值含冒号或特殊字符时用 JSON 双引号。日期用 ISO 格式。
