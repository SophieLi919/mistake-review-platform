# 错题分析平台

> Mistake Review Platform · 数学/语文/英语三科错题 AI 分析 Skill（原 mistake-workbench 三科版）

> 不是把错题发给 AI 让它讲一遍，而是先找到「考什么」的课标标尺，再把整张卷子交给 AI 按能力维度分析、累积、出题、复查——最后长成一个手机可看的错题工作台网页。

这是一套家用错题分析 AI Skill，覆盖**数学 / 语文 / 英语**三科，适用于 Claude Code、Codex、腾讯 WorkBuddy 等支持 Skill 的 AI 助手。所有数据留在你自己的电脑上：没有服务器，没有账号，没有上传。

## 三科分工

| Skill | 课标尺子 | 教材 |
|---|---|---|
| `mistake-workbench` | 2022 数学课标 · 11 个核心素养表现 + 四大领域 | 内置北师大/人教/苏教版单元目标，其他版本按课本目录 |
| `chinese-workbench` | 2022 语文课标 · 四大核心素养 + 六大学习任务群 | 部编版 |
| `english-workbench` | 2022 英语课标 · 一级（3～4年级）四大素养 + 六要素 | 外研社三年级起点 |

三科同一套脚本和工作台，数据分科存放、不混用、不横向排名。

## 它做什么

1. **先问三件事**：孩子怎么称呼、几年级、哪个版本的教材。
2. **收整张卷子**：每页一张照片，不只拍错题；但**口述优先**——具体错字、数字、扣分一律以家长口述为准，AI 不靠读图瞎猜。
3. **三层映射**：每条结论归入三层——**需巩固**（有错题证据）/ **已具备**（做对不用练）/ **未覆盖**（课标要求但还没考到的盲区）。
4. **只写掌握程度，不写分数**：分数留在卷子笔记里当证据。
5. **累积易错点**：每个坑一份笔记，跨卷子累积，状态在「活跃/减少/消失」之间流动。
6. **长出练习**：题目全部从孩子真实错题和课本原文里长出来，不编新场景。孩子版+妈妈版两份。
7. **一键生成工作台网页**：错题卡、课标对标、闯关题库、卷子图库，手机可看。
8. **期末按易错点出复习卷**。

## 安装

**方法一：把仓库链接发给你的 AI（最省事）**

复制本仓库地址，发给你正在用的 AI 助手，说一句：

> 帮我安装这个错题工作台 skill：https://github.com/SophieLi919/mistake-review-platform

支持 Skill 的 Agent（WorkBuddy、Claude Code、Codex 等）会自己拉取并装好。装完重启对话就能用。

**方法二：git**

```bash
git clone https://github.com/SophieLi919/mistake-review-platform ~/.claude/skills/mistake-workbench-suite
```

按需把其中一科或三科的文件夹拷进你的 Skill 目录：

- Claude Code：`~/.claude/skills/`
- Codex：`~/.codex/skills/`
- WorkBuddy：`~/.workbuddy/skills/`

**方法三：无 git**

GitHub 页面 → Code → Download ZIP，解压后把想用的科目文件夹拷进上面的 Skill 目录，重启 AI 助手即可。

**进阶：多科合并工作台**

如果装了多科，可以用根目录的 `build_merged.py` 把几科的工作台合成一个网页，顶部有「语文 / 数学 / 英语」切换条，一个文件看全部（用法见脚本头部注释）。

## 快速上手

装好后在 AI 助手里说：

- 「数学错题工作台，整理这张卷子」+ 发卷子照片
- 孩子做完练习 → 「批改练习」
- 「更新工作台」→ 重新生成网页
- 「看课标覆盖」→ 查四大领域/核心素养哪些考过、哪些是盲区
